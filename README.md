# 📊 Dashboard Comercial - Power BI

Este repositório contém um projeto de Business Intelligence voltado para a análise de desempenho comercial global. O objetivo principal do painel é consolidar métricas de receita, volume de vendas, ticket médio e perfil demográfico de clientes para apoiar a tomada de decisão gerencial.


---

## 🚀 Principais Métricas e Insights do Negócio
* **Receita Consolidada:** \$548,51 Milhões.
* **Volume de Vendas:** 2,12 Milhões de produtos comercializados.
* **Ticket Médio por Venda:** \$478,65.
* **Base Ativa de Clientes:** 18,48 Mil clientes atendidos.
* **Comportamento do Consumidor:** O público feminino representa a maior fatia do faturamento, sendo responsável por 55,20% das vendas (1,17 Mi).
* **Análise de Marcas:** A marca **Contoso** destaca-se como líder absoluta de mercado, gerando \$0,22 Bi em faturamento.

---

## 🛠️ Tecnologias e Recursos Utilizados
* **Power BI Desktop** para desenvolvimento dos visuais e relatórios.
* **Power Query (M)** para extração, transformação e limpeza dos dados (ETL).
* **Linguagem DAX** para criação de medidas calculadas e indicadores (KPIs).
* **Modelagem de Dados** (Ex: Estrutura Star Schema com tabelas Fato e Dimensão).
* **Design e UX/UI** focado em usabilidade e contraste para leitura rápida.

---

## 📁 Como visualizar o projeto
1. Baixe o arquivo `Dashboard_Comercial.pbix` presente neste repositório.
2. Certifique-se de ter o Microsoft Power BI Desktop instalado em sua máquina para abrir e interagir com os filtros.
